# Fortranによる10000万の神経細胞シミュレーションで疑似EEGを出す

## 1. 目的
Fortranを用いて、神経細胞の膜電位と発火を簡易的に再現する。

また、以下の技術を使用し、複数ニューロンを効率的に計算することを目的とする。

- サブルーチンとmoduleによる処理の分割
- OpenMPによる並列計算
- MPIによる分散計算
- Pythonによる結果の可視化

最終的には、10000個のニューロンを計算し、平均膜電位を擬似的な脳波として表示する。

## 2. シミュレーションモデル
神経細胞モデルには、LIFモデル（Leaky Integrate-and-Fire model）を使用した。

>Leaky integrate-and-fire モデル https://compneuro-julia.github.io/neuron-model/lif.html

また、10000個のニューロンには、異なる入力電流とランダムノイズを与えて実際の脳波っぽく表示させた。脳波にまとめる部分は全ニューロンの平均膜電位を用いた。

## 3. プログラム構成・説明
ディレクトリ構造は以下になってる。

```plain text
.
├── main.f90
├── neuron.f90
├── Makefile
├── show_mpi.py
├── eeg.dat
└── eeg.png
```

### main.f90
シミュレーションの中心部分

主な機能は以下である。
- MPIの初期化
- 10000個のニューロンを各プロセスへ分割
- ニューロンの膜電位計算
- 全ニューロンの平均膜電位の計算
- eeg.datへの保存
- MPIの終了

### neuron.f90
LIFモデルの膜電位更新処理を、サブルーチンとして定義する。

主な処理は以下である。

- 膜電位の更新
- 発火判定
- 発火後のリセット

### show_mpi.py
eeg.datを読み込み、平均膜電位の時間変化をグラフ化する。

```bash
python show_mpi.py
```
を実行するとeeg.pngが作成される。

## 4. 実行結果
MPIを4プロセスで実行した結果、10000個のニューロンを2500個ずつに分けて各ニューロンには異なる入力電流とランダムノイズを与えた。
また、Github のCode SpaceではMPIが4プロセルが上限であったため4つとなった。

各時点における全ニューロンの膜電位をMPIで集約し、平均膜電位をeeg.datへ保存した。

Pythonで可視化することで、時間とともに変動する擬似的な脳波を確認できた。

## 5. 考察
LIFモデルを使用することで、入力による膜電位の上昇、発火、リセットという神経細胞の基本的な動きを簡単に再現できた。

また、MPIを使用することで、10000個のニューロンを複数のプロセスに分割して計算できた。これにより、大規模なシミュレーションでは並列・分散処理が有効であることを確認できた。

一方、今回作成した擬似脳波は、全ニューロンの膜電位を単純に平均したものである。そのため、実際の頭皮EEGを正確に再現しているわけではない。

実際には、
- もっと多くのニューロンの相互接続
- 刺激の多様性の考慮
など多くの考慮すべき点があると考える。
